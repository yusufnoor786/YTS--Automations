# Privacy Policy — YTS Autopilot

_Last updated: 24 November 2026_

YTS Autopilot is a personal automation tool run by its owner (yusufnoor786) for the owner's own accounts only:
Instagram @bliss_nglow, @wanted_level_yts and @darrdiaries_yts, and YouTube @blissnglowshorts, @WantedLevel-YTS and @DarrDiaries-YTS.
It is not offered to, or used by, anyone else.

**What it accesses**
- Google Drive: video files in the owner's "YTS" folder, read in order to post them and moved into sub-folders after posting.
- YouTube (YouTube API Services): it uploads the owner's videos to the owner's channels and reads those channels' public statistics.
- Instagram / Meta: it publishes Reels to the owner's accounts and reads their follower and post statistics.

**What it stores**
- File checksums, file names, post IDs, links and daily follower counts, kept in this repository (`state/`) so that videos are never posted twice and a dashboard can be shown.
- Access tokens are stored only as encrypted GitHub Actions secrets.
- No data about other people is collected. Nothing is sold or shared with third parties.

**Public niche research**
Public YouTube search results in the owner's niches (video titles and view counts) may be read to see what topics are popular.
Only aggregated weekly summaries are kept; raw API data is refreshed or deleted within 30 days.

**Data deletion**
Stored YouTube API data (video IDs and statistics) is deleted within 30 days after access is revoked, or immediately on request
to the contact address below.

**Google and YouTube**
This tool uses YouTube API Services. See the YouTube Terms of Service (https://www.youtube.com/t/terms) and the
Google Privacy Policy (https://policies.google.com/privacy). Access can be revoked at any time at
https://myaccount.google.com/permissions or https://security.google.com/settings/security/permissions.

**Contact:** yusufnoor786@gmail.com
